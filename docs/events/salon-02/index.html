VOL. 02芯沙龙

下一期聊点什么？

第一期芯沙龙之后，我们想把「下一期讲什么」这件事交给社区决定。

下面这份候选清单会一直开着。每个候选主题都配了大致的形式与时长， 你可以到[投稿页](../../contribute/index.html)投票、补充，或者自荐来讲。

候选主题

1. 个人网站从零到上线

看别人的个人主页觉得好看，但不知道从哪开始。 从选域名、买服务器（或者干脆用 GitHub Pages 免费托管）， 到排版、配色、上线，一次走完。

  • 形式：动手工作坊
  • 时长：约 90 分钟
  • 前置：不需要写过后端，会基本的文本编辑即可

2. Agent 工作流实战

把 Agent 接到真实的资料、代码和文档上，做一条能反复使用的工作流。 包括怎么写提示词、怎么让它读你的文件、怎么把结果落成文件。

  • 形式：主题分享 + 现场演示
  • 时长：约 60 分钟
  • 前置：用过任意一种 AI 对话工具

3. IC 方向分享：你在做什么

由学院同学自己讲：模拟、数字、射频、器件、EDA，各自日常在做什么， 需要什么基础，怎么入门。每个方向 15 分钟。

  • 形式：多主讲短分享
  • 时长：约 75 分钟
  • 讲师：公开征集，欢迎自荐

4. 竞赛经验与避坑

从选题、组队、时间安排到提交材料，讲清楚一次竞赛的完整流程， 重点讲那些第一次参加一定会踩的坑。

  • 形式：圆桌对谈
  • 时长：约 60 分钟
  • 讲师：征集有参赛经历的同学

怎么投票

到[投稿页](../../contribute/index.html)提交，格式：

主题编号：
想加的内容：
是否愿意主讲：

票数会实时反映到社区群里，得票最高的两个主题进入下一期议程。

想自己讲一场？

非常欢迎。我们对讲师的要求只有三条：

  1. 讲你自己真正做过的事，不用讲得很全
  2. 至少留 15 分钟给提问
  3. 讲义或示例文件愿意公开，留在资源库里给后面的人用

有意向请通过[加入我们](../../join/index.html)页面的联系方式找我们。
