# AI 芯动力官网 · 交付与发布说明

本次补充每日资讯同步、发布保护和可校验交付包。原有页面模板、CSS、JavaScript、照片及字体文件保持原样。

## 交付包的用途

ZIP 用于归档、阅读和本地预览，不包含 Git 历史。日常编辑与发布应使用从官网仓库完整克隆的工作副本。

包内的 `DELIVERY.json` 记录对应提交、打包时间、本地未提交状态以及每个文件的大小和 SHA-256。与 ZIP 同名的 `.sha256` 文件记录整个压缩包的校验值。它们用于检查传输完整性；发布前仍需核对版本。

校验收到的 ZIP：

```bash
python3 scripts/package_release.py --verify 交付包.zip
```

校验只读取文件，不修改仓库或电脑网络。文件缺失、内容改变或出现清单之外的文件都会失败。

## 正常更新网站

1. 从 `https://github.com/uestc-aic/uestc-aic.github.io.git` 克隆仓库，进入目录。
2. 每次编辑前先同步 main；遇到冲突先处理，避免用旧副本覆盖新内容。
3. 修改对应的内容文件。可先运行以下检查：

```bash
python3 -m unittest discover -s tests -v
python3 scripts/build.py
python3 scripts/verify.py
```

4. 把本次修改加入暂存区，检查差异，正常提交并推送 main。
5. 在 Actions 的 **Update and deploy website** 中确认构建和发布成功。

修改文档后，网站「运维手册」页面会随构建更新。页面模板、布局和字体的修改应另行确认范围。

## 自动采集与发布

- 计划每天北京时间 03:10 运行，实际开始时间受 GitHub 排队影响。
- 自动流程依次完成：采集、生成网页、检查、按需提交、发布。
- 没有内容变化时，不会为了更新抓取时间产生提交。
- 去重和异常状态通过 Actions 缓存保留；缓存失效时仍会用现有数据去重。
- 全部来源失败或网页检查失败时停止，保留已发布官网。部分来源异常会在运行摘要中列出。
- 手动运行时可指定来源；「试运行」不会提交或发布，也不会保存新的采集状态。

当前 Pages Source 为 GitHub Actions，运行文件为 `.github/workflows/pages.yml`。不需要再安装交付旧包中的独立 `collect.yml` 或 `dist` 版发布流程。

## 普通 Git 推送不可用时

网络故障应先定位到具体设备和链路。原交付包的 hosts 修复脚本只对运行者本机生效，本次未运行，也未将其加入网站仓库。

若 Git 推送不可用、但已登录的 GitHub CLI 能正常访问 API，可在完整且已同步的仓库中使用备用工具。先明确暂存本次文件，再预览：

```bash
git add content/events.json
python3 scripts/push_via_api.py --message "更新活动信息" --dry-run
python3 scripts/push_via_api.py --message "更新活动信息"
```

工具仅提交暂存区版本。未暂存的新文件或后续修改不会上传；默认不删除远端文件。需要删除时，应先明确暂存对应删除、检查试运行结果，再显式使用 `--allow-delete`。网站关键文件不允许删除；旧的 `--no-delete` 参数仍兼容。

工具会拒绝无 Git 记录的解压副本、错误仓库或分支、空文件清单、缺失关键文件、未解决的合并冲突、本地 HEAD 与远端不一致，以及不完整的远端文件树。工作流文件始终保留，须通过正常 Git 或 GitHub 网页修改。

API 提交不会移动本地 HEAD。提交成功后，应先同步远端并核对本地改动，再继续编辑；同步失败时不要重复提交旧副本。工具不会强行覆盖处理期间产生的新提交。

## 生成修订交付包

先把新增文件加入 Git，检查并完成提交。生成命令会重新构建、检查网页，打包 Git 已记录的文件，并校验压缩包：

```bash
python3 scripts/package_release.py --output ../uestc-aic-website-delivery.zip
python3 scripts/package_release.py --verify ../uestc-aic-website-delivery.zip
```

未被 Git 记录的临时文件、Git 历史和采集运行缓存不会打入包内。如果打包时还有未提交修改，`DELIVERY.json` 会列出，不能把它当作干净提交的逐字节副本。
